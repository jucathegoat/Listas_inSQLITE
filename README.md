# Listas (SQLite)

Um aplicativo simples e direto para gerenciamento de listas local, desenvolvido em Flutter. O projeto utiliza o SQLite para armazenar as informações direto no dispositivo, garantindo que os dados fiquem salvos mesmo se o app for fechado ou o celular fique sem internet.

## 📱 O que o app faz
* Criação e exclusão de listas personalizadas.
* Adição de itens com persistência local em banco de dados (SQLite).
* Interface limpa e responsiva.

👉 [Baixar APK do Aplicativo] COMING SOON

## 💻 Como rodar o projeto localmente

Caso queira clonar o repositório e rodar o código na sua máquina:

1. **Pré-requisitos:** Certifique-se de ter o Flutter instalado e configurado (`flutter doctor`).
2. **Clonar o repositório:**
   ```bash
   git clone https://github.com https://github.com/jucathegoat/Listas_inSQLITE
   ```
3. **Instalar as dependências:**
   ```bash
   cd listas
   flutter pub get
   ```
4. **Executar o app:**
   ```bash
   flutter run
   ```

## 🛠️ Tecnologias utilizadas
* **Flutter & Dart** (Frontend)
* **Sqflite** (Banco de dados local)
